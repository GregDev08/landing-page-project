# Portfolio - Jose Melo

Portfolio personal diseñado para posicionar a Jose Melo como Python Developer enfocado en datos: ETL, análisis, APIs, scraping y automatización.

## 🧭 Qué incluye
- Hero moderno que comunica especialización en Python y soluciones de datos.
- Sección "Sobre mí" con énfasis en pensamiento analítico, automatización y experiencia profesional.
- Stack técnico dividido en categorías: Lenguajes, Backend, Bases de datos, Data, ETL y Herramientas.
- Proyectos destacados orientados a pipelines de datos y scraping.
- Contacto con formulario y enlaces directos a email, LinkedIn, GitHub y CV.
- Diseño oscuro, responsivo y con animaciones ligeras.

## 🚀 Cómo ejecutar
1. Abre `index.html` en tu navegador.
2. Asegúrate de mantener `style.css` y `script.js` en la misma carpeta.
3. Si deseas desplegarlo, usa cualquier host estático como Vercel, Netlify o GitHub Pages.

## 📁 Estructura de archivos
- `index.html` — estructura principal del sitio.
- `style.css` — diseño, layout y animaciones.
- `script.js` — interacciones: menú móvil, barra de progreso, revelado en scroll, partículas y formulario de contacto.
- `assets/` — recursos complementarios como el CV.
